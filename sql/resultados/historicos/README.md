# Mediciones historicas (serie principal)

Esta carpeta conserva 21 archivos CSV historicos correspondientes a 20 combinaciones consulta-escala.
La combinacion C1 con 1000 registros se guardo en dos archivos: 38 y 39.
Las restantes 19 combinaciones corresponden a los archivos 40 a 58.

Los CSV `06_C*.csv` de la carpeta superior corresponden a una segunda serie experimental.
No deben mezclarse las dos series ni interpretarse como una sola ejecucion.
El informe PDF explica el protocolo y compara los resultados.
